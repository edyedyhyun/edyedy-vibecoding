# Snake Game

바이브코딩으로 고전게임 만들기의 첫 번째 작업물입니다. Claude Code Sonnet이 구현하고, Codex가 단계별 지시·검증·단일 파일 패키징을 진행했습니다.

## 실행

이 폴더를 내려받아 `snake.html`을 브라우저로 여세요. 스타일과 JavaScript가 포함된 단일 HTML 파일이므로 설치, 서버, 인터넷 연결이 필요하지 않습니다. GitHub에서는 원본 파일을 다운로드한 뒤 브라우저로 여세요.

- 이동: 방향키 또는 W·A·S·D
- 일시정지 / 계속: Space, P 또는 화면 버튼
- 먹이 하나당 10점, 벽이나 자기 몸과 충돌하면 게임 오버
- 게임 오버 후 다시하기
- 좁은 화면에서는 방향 버튼 사용 가능
- 최고 점수는 브라우저 로컬 저장소 사용. 저장이 제한돼도 게임은 동작합니다.

## 소스 구성

| 파일 | 역할 |
| --- | --- |
| `snake.html` | 바로 실행하는 단일 파일 완성본 |
| `index.html` | 소스 파일을 불러오는 개발용 화면 |
| `engine.js` | 이동, 먹이, 충돌, 점수 등 게임 규칙 |
| `app.js` | 화면 그리기, 입력, 일시정지, 최고 점수 저장 |
| `engine.test.js` | 게임 규칙 및 방향 전환 오류 회귀 테스트 |
| `build.py` | 소스를 단일 HTML 파일로 묶는 빌드 스크립트 |

## 수정 후 빌드와 검증

이 폴더에서 실행합니다. 게임 자체의 실행에는 Python이나 Node.js가 필요하지 않습니다.

```sh
python3 build.py
node --test engine.test.js
```

`snake.html`을 직접 고치기보다 `index.html`, `engine.js`, `app.js`를 수정한 뒤 빌드하세요.

## 제작 중 확인한 문제

- 시작 안내의 CSS 표시 규칙이 `hidden` 속성보다 우선해서 안내가 남는 문제 수정
- 한 번 이동하기 전에 방향을 두 번 입력하면 반대 방향으로 꺾이는 문제 수정
- 일시정지 키를 길게 눌렀을 때 반복 입력을 무시하도록 보강

게임 규칙 테스트 11개와 브라우저에서 시작·방향 입력·일시정지·재개·게임 오버·재시작을 확인했습니다. 화면 검증은 로컬 미리보기에서 진행했으며, 모든 PC의 로컬 파일 실행 환경을 검증한 것은 아닙니다.
