# 별빛 순찰대 · Star Patrol

오리지널 갤러그 스타일 고정 화면 우주 슈팅 게임. 순수 JS 엔진 + 캔버스 렌더링, 외부 자산·사운드 없음, 오프라인 동작.

## 파일 구성

- `engine.js` — 입력/그리기와 무관한 순수 게임 로직 (상태, 시뮬레이션, 충돌). CommonJS + 브라우저 전역(`StarPatrolEngine`) 겸용.
- `app.js` — DOM/캔버스 렌더링, 키보드·포인터 입력, localStorage 최고 기록 연동.
- `index.html` — 개발용 진입점 (`engine.js`, `app.js`를 분리 로드).
- `build.py` — `index.html` + `engine.js` + `app.js`를 합쳐 `star-patrol.html`(standalone) 생성.
- `engine.test.js` — `node --test`로 실행하는 엔진 규칙 테스트.

## 실행

```
open index.html                 # 개발 중 바로 열어보기
python3 build.py                # star-patrol.html 생성 (배포용 단일 파일)
node --test engine.test.js
```

## 조작

- 시작 화면에서 연사 속도(보통 0.24s / 빠름 0.16s) 선택 후 출격.
- 키보드: ← → 또는 A D 이동, Space 발사(누르고 있으면 연사), P 또는 Esc 일시정지/재개, R (일시정지·게임오버 상태에서) 대기 화면으로.
- 모바일: 화면 하단 좌/발사/우 버튼을 누르고 있는 동안 입력 유지, 손을 떼거나 포인터가 취소되면 즉시 해제.
- 탭이 백그라운드로 가면(blur/hidden) 자동으로 입력이 정리되고 플레이 중이면 일시정지됩니다.

## 게임 규칙 요약

- 4행 8열 편대가 좌우로 오가며, 일정 간격으로 개별 적이 플레이어를 향해 다이빙하고 총알을 발사합니다.
- 홀수 행(코랄)이 짝수 행(엠버)보다 점수가 높습니다.
- 웨이브가 오를수록(상한 있음) 편대 속도, 다이빙 빈도/동시 다이버 수, 총알 속도가 증가합니다.
- 목숨 3개, 피격 시 무적 시간 부여. 최고 점수는 게임 중에도 갱신 시 안전하게 localStorage에 저장됩니다.

## 배포 파일

`star-patrol.html` 하나만 다운로드한 뒤 브라우저에서 열면 인터넷 없이 실행됩니다. 코드 페이지 자체를 저장하지 말고 GitHub의 **Download raw file**을 사용하세요.

## 확인 결과와 한계

- 엔진 테스트 21개 통과: 충돌, 목숨/무적, 점수, 입력, 재시작, 웨이브 전환, 발사 간격, 잘못된 최고 기록 값 등.
- 데스크톱 브라우저에서 두 연사 모드, 오른쪽 이동, 적 격추와 점수 증가, 일시정지·재개·처음으로 버튼, 최고 기록 유지, 320px 배치를 확인했습니다.
- 모바일 화면에서도 재개/처음으로 버튼을 사용합니다. 실제 휴대폰 멀티터치와 모든 브라우저 호환성을 검증한 것은 아닙니다.
- 최고 기록은 브라우저별로 저장되며 동기화되지 않습니다. 저장소가 차단되어도 게임은 실행되지만 기록은 유지되지 않을 수 있습니다.
- 두 연사 설정은 같은 최고 기록을 공유합니다. 공정한 순위 경쟁용 기록이 아닙니다.
- 사운드, 보스, 온라인 순위, 원작의 포획/합체 기능은 없습니다.
- 웨이브 사이에는 남은 적탄을 지웁니다. 모든 무작위 상황에서의 난이도 균형을 보장하지는 않습니다.
