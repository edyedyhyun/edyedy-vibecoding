# 작은 창고 · Sokoban

오프라인 HTML5 상자 밀기 퍼즐. `sokoban.html` 하나를 내려받아 브라우저에서 열면 됩니다. 외부 라이브러리나 네트워크 요청은 없습니다.

- 방향키/WASD 또는 화면 버튼: 이동. 상자는 하나씩 밀 수 있고 당길 수 없습니다.
- Z/한 수 되돌리기: 이동·밀기·상자·작업자 위치를 되돌립니다. 횟수 제한 없음.
- R: 현재 판 재시작. 목록에서 5개 입문용 맵 선택 가능.
- 목표 위가 아닌 벽 모서리에 상자가 들어가면 경고합니다. 벽에 붙거나 상자끼리 막힌 모든 불가능 상태를 검출하는 기능은 아닙니다.
- 기록은 메모리에만 남습니다. 새로고침하면 초기화됩니다. 별도 저장/불러오기 없음.

## 구현과 검증
직접 구현. 특정 외부 AI 모델을 사용했다고 표기하지 않습니다. 원작 이미지·맵을 복제하지 않은 작은 연습용 맵입니다.

`python3 build.py`로 engine.js/app.js를 단일 HTML에 포함합니다.
`node --test tests/engine.test.js`: 14개 테스트(벽/상자 충돌, 목표 판정, undo, 맵별 BFS 경로 탐색 및 재생).

맵별 해답 경로(스포일러): U / RUDLLLU / UULLDDRRR / RUULURDDDLLUU / ULURDRURDRU. U/R/D/L은 상/우/하/좌입니다. 자동 탐색 결과이며 사람 풀이 기록이 아닙니다.

실제 브라우저에서는 두 번째 맵에서 ULLDLUU로 구석 갇힘(이동7/밀기3)을 재현하고 한 수 되돌리기(이동6/밀기2)를 확인했습니다. 되돌리기 한 번만으로 왼쪽 벽에 붙은 상자가 다시 풀린다고 보장하지 않습니다. 재시작 후 탐색 경로를 화면 버튼으로 재생해 이동7/밀기2/목표2개 완료를 확인했습니다. 390px 폭에서 가로 넘침 없음. 실제 휴대폰 하드웨어 테스트는 하지 않았습니다.

images/cover.webp는 표지 일러스트, 다른 WebP는 실제 게임 캡처입니다.
