# 감자배구

추억의 감자배구에서 착안해 새 캐릭터와 화면으로 만든 HTML5 게임입니다. 컴퓨터 상대 또는 같은 키보드로 2명이 플레이할 수 있습니다. 먼저 7점을 얻으면 승리합니다.

## 실행

`potato-volleyball.html`을 원본 파일로 내려받고 PC 브라우저로 열어 주세요. 인터넷 연결, 설치, 외부 라이브러리가 필요하지 않습니다. GitHub의 코드 표시 페이지 자체를 저장하는 대신 파일의 다운로드 버튼을 사용하세요.

## 조작

| 기능 | 조작 |
| --- | --- |
| 왼쪽 감자 이동 / 점프 | A·D / W |
| 오른쪽 감자 이동 / 점프 (2인용) | ←·→ / ↑ |
| 시작·서브·다음 랠리·다시하기 | 화면 버튼 또는 Space |
| 일시정지·재개 | 화면 버튼 또는 P |
| 컴퓨터 / 2인용 선택 | 모드 변경 |

득점 뒤에는 다음 랠리 버튼으로 서브 준비 상태로 돌아가고, 서브하기를 눌러 공을 시작합니다. 창을 떠나면 자동으로 일시정지하며 직접 재개해야 합니다. 컴퓨터 상대는 단순한 추적 방식입니다. PC 키보드 플레이를 기준으로 제작했습니다.

## 소스

- `index.html`: 화면과 스타일
- `engine.js`: DOM과 분리한 게임 규칙 및 물리 계산
- `app.js`: 입력·컴퓨터 상대·Canvas 렌더링
- `engine.test.js`: 기본 서브·득점·경계·승리·속도 등 회귀 검사
- `build.py`: 소스를 단일 HTML로 묶기
- `potato-volleyball.html`: 배포용 단일 파일

개발 중에는 `index.html`을 브라우저로 열거나 로컬 정적 서버에서 확인할 수 있습니다.

```sh
node --test engine.test.js
python3 build.py
```

그림은 Canvas에서 직접 그립니다. 원작 실행 파일이나 이미지 자산은 포함하지 않습니다.
