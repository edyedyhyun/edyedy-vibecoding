# 작은 궤도 · LITTLE ORBIT

범퍼 3개와 좌우 플리퍼로 만든 오리지널 로컬 HTML5 핀볼입니다. `pinball.html`을 내려받아 브라우저로 열면 됩니다. 외부 라이브러리나 네트워크 연결은 필요 없습니다.

## 조작
- Space 또는 공 발사: 준비 상태에서 발사
- ← / A, → / D: 누르는 동안 해당 플리퍼 올리기
- 화면 좌우 버튼: 누르는 동안 작동, 동시 터치 대응
- P / Esc 또는 정지 버튼: 일시정지/재개, 탭을 떠나면 자동 정지
- 새 게임: 점수와 공을 초기화
- 공을 발사하기 전 플리퍼 회전 속도55%/100% 선택

범퍼마다100점, 공3개. 점수는 공을 잃어도 유지되고 새 게임에서 초기화됩니다. 비교를 위해 발사 위치/속도는 매번 같습니다. 별도 발사 통로, 멀티볼, 사운드, 최고점 저장, 틸트 기능은 없습니다. 공과 선분 충돌 및 회전 표면 속도를 쓰는 간소화 물리로 실제 핀볼 기계를 정밀 재현하지 않습니다.

## 개발/검증
`engine.js` 규칙, `app.js` 화면과 입력, `index.html` 레이아웃. `python3 games/pinball/build.py`로 단일HTML 생성.
`node --test games/pinball/engine.test.js` : 10개 검사 통과(발사 경로/중복 발사/정지/범퍼/공 소모/종료/고속 벽충돌/플리퍼 반응/좌우 대칭/초기화).

실제 브라우저에서 첫 버전 발사0점·남은공2, 수정 후 범퍼100점·남은공2, 55% 선택/발사/정지, 390px 배치를 확인했습니다. 첫 발사 위치가 가이드 아래여서 즉시 튕겨 내려오던 문제를 수정했습니다. 모바일 보드높이58vh→42vh로 버튼이 화면에 들어오도록 조정했습니다.

통제된 엔진 비교: 동일 공(x205,y640,vy180)에 왼쪽 플리퍼를 작동시킨0.05초 뒤 위쪽 속도 약782(55%) vs1236(100%) 게임좌표/초. 사람 플레이 점수 비교나 재미의 증명이 아닙니다. 장시간 밸런스와 실제 휴대폰 멀티터치는 미검증.
