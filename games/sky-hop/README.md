# 구름새 · Sky Hop

민트·크림·네이비 하늘 위를 나는 작은 새를 날갯짓으로 조종해, 산호색·청록색 문 사이의 틈을 통과하는 오프라인 HTML5 게임입니다.

> **원작 관련 안내**: 이 게임은 “탭해서 날갯짓하며 장애물 틈을 통과한다”는 일반적인 장르 방식에서 영감을 받았지만, 특정 상표 게임의 복제품이 아닙니다. 새·문·배경·이름은 모두 캔버스로 직접 그린 독자 디자인이며, 외부 스프라이트·이미지·폰트·소리를 사용하지 않습니다.

## 실행 방법

- **`sky-hop.html`** 을 내려받아 브라우저로 열면 됩니다. 인터넷 연결, 다른 파일, 빌드 도구가 필요 없습니다.
- 개발용 `index.html`은 `engine.js`, `app.js`와 같은 폴더에서 열면 동작합니다.
- 소스를 고친 뒤에는 `python3 build.py`로 `sky-hop.html`을 다시 만듭니다 (표준 라이브러리만 사용).
- 엔진 테스트: `node --test engine.test.js` (Node.js 18 이상 권장, 외부 패키지 없음)

## 조작법

| 입력 | 동작 |
| --- | --- |
| `Space` / `↑` / `W` | 날갯짓 (대기 화면에서는 **게임을 시작하면서 바로 날갯짓**) |
| 마우스 클릭 / 터치 (게임 화면) | 날갯짓 |
| `P` 또는 `Esc` | 플레이 중 일시정지, 일시정지 중 재개 |
| `R` 또는 `Enter` | 게임 오버(또는 일시정지) 상태에서 다시 시작 |
| 화면 버튼 | 정지 / 계속하기 / 다시 시작 / 다시 하기 |

- 키를 누르고 있어도 날갯짓은 **한 번만** 일어납니다 (키 반복 입력 무시, 키를 뗀 뒤에만 다음 입력 인정).
- 게임 오버 상태에서 `Space`·클릭·터치는 무시됩니다. 다시 시작은 `R`/`Enter` 또는 버튼으로만 가능하므로, 죽을 때 누르고 있던 키로 실수로 재시작되지 않습니다. 다시 시작하면 “대기” 상태가 되고 첫 입력에서 시작합니다.
- 일시정지 중에는 `Space`·클릭이 재개하지 않습니다. `P`/`Esc`/‘계속하기’로만 재개하며, 재개 후 약 0.9초의 3‑2‑1 준비 시간 동안 새가 멈춰 있습니다.
- 탭이 숨겨지거나 창이 포커스를 잃으면 자동으로 일시정지됩니다.
- 버튼은 키보드 `Tab`으로 이동해 `Enter`로 누를 수 있습니다 (`Space` 키는 게임 입력을 위해 버튼 활성화에 쓰지 않습니다).

## 규칙

- 문 사이 틈을 지나가면 1점. 각 문은 한 번만 점수를 줍니다.
- 문(위·아래)이나 바닥에 닿으면 게임 오버. 천장은 막힐 뿐 죽지 않습니다.
- 점수가 오르면 이동 속도가 조금씩 빨라지며, 상한이 있습니다.
- 최고 점수는 점수가 오르는 **즉시** 갱신되어 화면에 반영되고, 새 기록이 나올 때마다 브라우저 `localStorage`(`skyhop.best.v1`)에 바로 저장됩니다. 그래서 일시정지 후 다시 시작하거나 탭을 닫아도 기록이 남습니다.
- 게임 오버 화면의 “새 기록!”은 **그 판을 시작할 때의 최고 기록**(`runStartBest`)을 넘었을 때만 표시됩니다. 같은 점수(동점)는 새 기록이 아닙니다.
- 저장소가 막혀 있거나 실패해도 게임은 정상 동작하고, 그 경우 최고 점수는 새로고침하면 사라집니다.

## 튜닝 상수 (`engine.js` 상단)

| 상수 | 값 | 설명 |
| --- | --- | --- |
| `WIDTH` × `HEIGHT` | 420 × 600 | 논리 해상도 (화면 크기·DPR에 맞춰 캔버스가 확대) |
| `GROUND_H` | 56 | 바닥 높이 |
| `GRAVITY` | 1500 px/s² | 중력 |
| `FLAP_VELOCITY` | −430 px/s | 날갯짓 속도 (한 번에 약 62px 상승) |
| `MAX_FALL_SPEED` | 640 px/s | 낙하 속도 상한 |
| `SCROLL_SPEED` | 115 px/s | 시작 이동 속도 |
| `SPEED_PER_POINT` / `SPEED_BONUS_MAX` | 2 / 45 | 점수당 속도 증가 / 증가 상한 |
| `GATE_GAP` | 200 | 위·아래 문 사이 틈 |
| `GATE_WIDTH` / `GATE_SPACING` | 64 / 235 | 문 너비 / 문 사이 가로 간격 |
| `GAP_MARGIN` | 64 | 틈과 천장·바닥 사이 최소 여유 |
| `BIRD_HIT_RADIUS` | 11 | 충돌 반지름 (그려진 몸통 반지름 14보다 작아 관대함) |
| `MAX_FRAME_DT` / `SUBSTEP_DT` | 0.1 s / 1/60 s | 프레임 시간 상한 / 물리 하위 단계 최대 길이 |
| `RESUME_COUNTDOWN` | 0.9 s | 재개 후 준비 시간 |

## 구조

- `engine.js` — DOM 없는 순수 로직(UMD). 상태, 날갯짓, 일시정지/재개, 시간 진행, 충돌, 점수, 문 생성.
- `app.js` — 입력, 캔버스 렌더링(DPR 대응), HUD·접근성 상태 문구, 저장소.
- `index.html` — 마크업과 스타일. `build.py` — 위 두 스크립트를 인라인해 `sky-hop.html` 생성.
- `engine.test.js` — Node 내장 `node:test` 기반 엔진 테스트.

시간 진행은 프레임 시간을 `MAX_FRAME_DT`로 제한한 뒤 `SUBSTEP_DT` 이하의 균등한 조각으로 나눠 처리하며, 등가속 운동을 해석적으로 적분하므로 프레임 속도가 달라도 결과가 거의 같습니다.

## 접근성

- 점수·최고 점수는 HTML 요소로 표시되고, 상태(준비/플레이 중/일시정지/게임 오버)는 `aria-live="polite"` 영역에 문장으로 갱신됩니다. 점수가 오를 때마다 읽어 주지는 않습니다.
- 캔버스에는 `role="img"`와 설명 라벨이 있습니다.

## 한계

- 소리·효과음이 없습니다. 그래서 음소거 버튼도 없습니다.
- 충돌은 원↔직사각형입니다. 문의 둥근 모서리는 그림일 뿐 충돌 모양은 직사각형입니다.
- 스크린리더 사용자가 실시간으로 조작하며 플레이하기는 사실상 어렵습니다(반응 속도가 필요한 게임).
- 난이도 선택, 리더보드, 진동 피드백 등은 없습니다. 최고 점수는 기기·브라우저별로 따로 저장됩니다.
- 자동 검증은 엔진 단위 테스트와, 헤드리스 Chrome(Playwright)으로 한 입력·일시정지·게임 오버·재시작 흐름의 스크립트 확인까지입니다. 실제 터치 기기와 Safari·Firefox에서의 확인은 하지 못했습니다.
