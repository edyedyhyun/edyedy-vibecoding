# 눈덩이 한 바퀴 / Snow Roll

눈을 쌓고 밀어 연쇄로 적을 쓰러뜨리는 오리지널 HTML5 게임. 원작 그래픽·캐릭터·음원·맵을 사용하지 않았습니다.

## 실행
` snow-roll.html `을 내려받아 브라우저로 엽니다. 서버, 설치, 인터넷 연결 불필요.

## 조작
← → / A D 이동, Space 점프, Z 눈 던지기(길게 누르면 연속), X 가까운 눈덩이 밀기, P 일시정지.
화면 방향 버튼은 한 번 누르면 계속 걷고 같은 방향 재클릭 또는 ■로 멈춥니다. 화면 발사/점프/밀기는 클릭마다 한 번입니다.

## 규칙
4번 적중→눈덩이, 완성 후8초 뒤 해제. 덜 쌓인 눈은3초간 미적중시 해제.
가로70px/세로35px 이내에서 밀기. 보는 방향으로 굴립니다. 굴러가는 공은 플레이어에게 무해.
연쇄 타격200/400/600...점, 굴린 공이 화면을 떠나면100점. 첫 판2연쇄는700점.
3개 눈길, 기회3번, 피격 후1.8초 보호, 다음판 점수/기회 유지. 창 전환시 자동일시정지.

## 개발 및 검증
engine.js 규칙/물리, app.js 렌더링/입력, index.html 템플릿. `python3 build.py` 단일HTML 생성.
`node --test tests/engine.test.js`:16검사 통과.
실제브라우저: 얼린뒤0점, 거리밖밀기실패, 접근→밀기→3격파/700점/2연쇄/기회3 첫판완료. 2판진입/점프/일시정지/재시작 확인.390px가로넘침없음.
전체3판 수동완주와 장시간 난이도는 미검증. 단계별물리/해제/상단발판/낙하는 자동테스트검증.
images/cover.webp 생성표지, 나머지WebP는 실제게임캡처.
