# 길 하나 남겨두기 / Lane Escape

세 차선에서 내려오는 차량을 피하는 오리지널 HTML5 아케이드. 60초 완주가 목표이며 원작 이미지·캐릭터·음원을 사용하지 않습니다.

## 실행과 조작
`lane-escape.html`을 내려받아 브라우저로 엽니다. 서버·설치·인터넷 연결 불필요.
← → / A D: 한 차선 이동. 화면 버튼도 클릭마다 한 차선 이동합니다. P 또는 버튼: 일시정지. 창 전환시 자동 일시정지.
차에 닿으면 종료. 재시작마다 난수 초기값이 바뀌며 새로고침하면 첫 도로로 돌아갑니다. 최고 생존 시간은 허용되는 브라우저의 localStorage에 저장됩니다.

## 규칙
차선 이동100px/.22초. 배경·장애물속도180→340px/s(45초에 상한), 차량줄 생성간격1.25→.9초.
첫12초 한 줄에 한 대, 이후 두 대. 매 줄 한 차선을 남기며 지정한 빈 차선은 이전 빈 차선과 같거나 이웃합니다.
이동거리(속도적분/10)는 게임 수치이며 실제 속도/거리 측정값이 아닙니다.

## 검증
`python3 build.py` 단일HTML 생성. `node --test tests/engine.test.js`:13검사 통과.
100개 난수 초기값의 도로를 규칙 기반 자동조작으로60초 완주 검증. 인간 반응 시간이나 재미를 보장하는 검사는 아닙니다.
실제 브라우저: 가운데차선 무조작7.5초/144m/3대 충돌, 버튼 자동조작60초/1680m/102대 완주. 일시정지시간정지, 재시작, 새로고침최고기록유지 확인.390px가로넘침없음, 조작버튼844px화면내.
긴 세션의 체감난이도와 실제휴대폰 터치검증은 추가할 부분입니다. 최고기록저장이 차단돼도 실행됩니다.
images/cover.webp는 생성한 표지 일러스트, 나머지는 실제게임캡처입니다.
