# 지뢰찾기 — 바이브코딩으로 고전게임 만들기 02

`minesweeper.html`을 내려받아 PC 브라우저에서 엽니다. HTML 파일 하나에 코드와 스타일이 들어 있어 설치, 외부 라이브러리, 서버, 인터넷 연결이 필요하지 않습니다.

GitHub에서 파일을 열고 **Download raw file** 버튼으로 다운로드하세요. 소스 보기 페이지 자체를 저장하지 마세요.

- 초급 9×9, 지뢰 10개
- 첫 클릭과 인접 칸을 지뢰 배치에서 제외
- 연결된 빈칸과 경계 숫자 자동 열기
- 클릭으로 열기, 우클릭 또는 깃발 모드로 표시
- 방향키 이동, Enter/Space 선택, F 깃발 전환
- 안전한 71칸을 모두 열면 승리
- 남은 지뢰 표시는 `10 - 깃발 수`이며 깃발의 정답 여부를 뜻하지 않습니다.
- 시작 영역은 안전하지만 추측 없이 풀리는 판을 보장하지 않습니다.

## 개발

`index.html`, `engine.js`, `app.js`가 개발용 소스입니다.

```sh
python3 build.py
node --test engine.test.js
```

Claude Code Sonnet으로 단계별 구현했습니다. 기본 규칙 및 첫 클릭 보호를 자동 테스트하고 브라우저에서 조작을 확인했습니다. 화면 검증은 동일 파일을 localhost에서 제공해 수행했으며 모든 PC의 file:// 환경을 시험한 것은 아닙니다.
