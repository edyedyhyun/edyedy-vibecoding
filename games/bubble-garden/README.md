# 방울 정원 · Bubble Garden

방울에 적을 가두고 가까이 다가가 터뜨리는 오리지널 HTML5 플랫폼 게임입니다. 원작 캐릭터·그래픽·음원을 사용하지 않습니다.

## 실행
`bubble-garden.html`을 내려받아 브라우저로 열면 됩니다. 인터넷·설치·서버가 필요하지 않습니다.

- ← → 이동, ↑ 또는 Space 점프
- Z 방울 발사, X 가까운 방울 터뜨리기, P 일시정지
- 화면 버튼 지원. 짧게 누르면 한 걸음, 누르고 있으면 이동합니다.
- 포획 후 6초 안에 120px 이내로 접근해 터뜨립니다. 터뜨릴 때 100점입니다.
- 3개 스테이지, 판마다 기회 3개. 점수는 판별로 초기화됩니다.
- 1인용 소규모 프로토타입이며 소리·2인 모드는 없습니다.

## 개발
`engine.js`: 판정, `app.js`: 렌더링/입력, `index.html`: 화면.
`python3 games/bubble-garden/build.py`로 단일 HTML을 다시 만듭니다.
`node --test games/bubble-garden/tests/engine.test.js`로 12개 핵심 판정 테스트를 실행합니다.

## 확인한 내용
브라우저에서 포획 후 탈출(0점), 거리 밖 터뜨리기 실패, 가까이서 터뜨려 첫 판 완료(100점), 두 번째 판 전환을 확인했습니다. 390px 화면에서 가로 넘침이 없습니다. 전체 세 판을 사람 플레이로 완주했다고 주장하지 않습니다.

`images/cover.webp`는 표지 일러스트이며 나머지 WebP 4장은 실제 플레이 캡처입니다. 표지는 내장 image_gen 도구로 생성했습니다. 생성 지시는 `cover-prompt.txt`에 기록했습니다.
