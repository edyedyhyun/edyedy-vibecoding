# 오늘도 무사히 · 똥피하기

땅 위에서 좌우로 움직이며 하늘에서 떨어지는 귀여운 똥을 끝까지 피하는 오프라인 HTML5 게임입니다. 크림색 하늘, 네이비 글씨, 산호색·청록색 포인트로 캔버스에 직접 그렸고, 외부 이미지·폰트·소리·네트워크를 쓰지 않습니다. 원작 게임의 복제품이 아닌 독자 디자인입니다.

## 실행 방법

- **`poop-dodge.html`** 을 브라우저(Chrome·Safari·Firefox·Edge 최신 버전)로 열면 됩니다. 인터넷 연결, 다른 파일, 빌드 도구가 필요 없습니다.
- 개발용 `index.html`은 `engine.js`, `app.js`와 같은 폴더에서 열면 동작합니다.
- 소스를 고친 뒤에는 `python3 build.py`로 `poop-dodge.html`을 다시 만듭니다 (표준 라이브러리만 사용).
- 엔진 테스트: `node --test engine.test.js` (Node.js 18 이상 권장, 외부 패키지 없음)

## 조작법

| 입력 | 동작 |
| --- | --- |
| `시작하기` 버튼 | 게임 시작 (실수로 시작되지 않도록 버튼으로만 시작) |
| `←` `→` / `A` `D` | 누르고 있는 동안 이동 |
| 화면 아래 **◀ 왼쪽 / 오른쪽 ▶** 버튼 | 누르고 있는 동안 이동 (마우스·터치) |
| 게임 화면을 누른 채 끌기 | 손가락·마우스 쪽으로 이동 |
| `P` 또는 `Esc`, ⏸ 버튼 | 일시정지 / 계속하기 |
| `R` | 일시정지·게임 오버 상태에서 다시 시작 (플레이 중에는 무시) |

- 브라우저 창이 가려지거나 다른 탭으로 옮기면 자동으로 일시정지됩니다.
- 일시정지·재시작·게임 오버·창 포커스 이탈·터치 취소 시에는 눌려 있던 이동 입력이 모두 풀립니다. 재개한 뒤에는 키나 버튼을 다시 눌러야 움직입니다.
- 한글 자판 상태에서도 `A` `D` `P` `R`은 물리 키 위치 기준으로 동작합니다.

## 규칙

- 똥에 닿지 않고 오래 버티는 게임입니다. **생존 시간**과 **피한 똥**(바닥에 닿은 똥 수)이 표시됩니다.
- 최고 생존 시간은 기록을 넘어서는 순간부터 (0.1초 단위로) 바로 저장되므로, 도중에 탭을 닫아도 남습니다. 게임 오버 화면의 `기록 지우기`는 두 번 눌러야 지워집니다.
- 시간이 지날수록 똥이 더 빨리, 더 자주 떨어지지만 약 100초 이후에는 상한에서 멈춥니다.
- 똥이 떨어질 자리에는 바닥에 그림자가 미리 나타납니다.

## 튜닝 상수 (`engine.js`)

| 항목 | 값 |
| --- | --- |
| 논리 캔버스 | 480×600 (화면 크기에 맞춰 축소, 320px 폭까지 대응) |
| 플레이어 그림 / 충돌 상자 | 44×56 / 28×40 (그림보다 작게) |
| 똥 그림 / 충돌 원 반지름 | 22 / 15 |
| 이동 속도 / 가속 | 330 px/s / 2800 px/s² |
| 낙하 속도 | 170 → 380 px/s (100초에 걸쳐 선형 증가, 이후 고정) |
| 생성 간격 | 0.95 → 0.42 초 (±20% 무작위) |
| 최소 반응 시간 | 약 1.34초 (화면 위에 나타나서 머리 높이에 닿기까지, 최고 속도 기준) |
| 프레임당 최대 dt / 하위 단계 | 1/20초 / 1/120초 |

## 공정성 장치

화면 폭 전체가 막히는 상황이 생기지 않도록, 엔진 안에 보이지 않는 **안전 통로**(폭 110px)가 천천히(최대 100px/s) 좌우로 떠다니고 그 안에는 똥을 만들지 않습니다. 생성 당시 비워 둔 위치와 현재 안전한 위치는 다를 수 있습니다. 생성 시점의 통로 이력을 따라가는 자동 조종이 6개 시드에서 3분간 생존하는 테스트를 통과했습니다. 모든 무작위 배치에서 회피 가능함을 증명한 것은 아니며, 실제 난이도는 추가 플레이로 조정할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `engine.js` | 순수 게임 로직 (DOM 없음): 상태, 이동·입력 취소, 난이도, 충돌, 점수, 저장값 해석 |
| `app.js` | 캔버스 그리기, 키보드·포인터 입력, 일시정지, 기록 저장 |
| `index.html` | 화면 구조와 스타일 (개발용, 스크립트는 외부 참조) |
| `build.py` | 스크립트를 인라인해 `poop-dodge.html` 생성 |
| `engine.test.js` | 엔진 테스트 (27개) |
| `poop-dodge.html` | 배포용 단일 파일 |

## 한계 (솔직하게)

- 데스크톱 브라우저에서 시작, 캔버스 드래그 좌우 이동, P 일시정지·재개, 게임 오버, 재시작, 새로고침 후 최고 기록 유지와 320px 화면 배치를 확인했습니다. 실제 휴대폰 터치와 여러 브라우저에서의 호환성은 별도 확인이 필요합니다.
- 소리와 진동은 없습니다.
- 최고 기록은 브라우저 저장소에 보관됩니다. 파일을 `file://` 로 열 때 저장소가 막혀 있거나 시크릿 모드이면 저장되지 않고, 이 경우 화면에 안내가 나오며 기록은 창을 닫을 때까지만 유지됩니다.
- 최고 기록은 브라우저·기기별로 따로 저장되고 서로 동기화되지 않습니다.
- 고주사율 화면에서도 게임 속도는 실제 시간 기준이지만, 매우 느린 기기에서 프레임이 20fps 아래로 떨어지면 게임이 그만큼 느리게 진행됩니다 (관통 방지를 위한 의도적 제한).
- 캔버스 끌기는 손가락 위치로 이동하는 방식이라 정밀한 미세 조작은 방향 버튼/키보드가 더 편합니다.
