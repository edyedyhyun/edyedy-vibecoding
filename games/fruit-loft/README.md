# 밤톨이의 과일 창고 / Fruit Loft

너구리풍 과일 수집에서 착안한 오리지널 로컬 HTML5 게임. 새 캐릭터와 배경, 4층 선반과 사다리, 순찰 적을 사용합니다. 기존 게임 그래픽·음원·맵은 사용하지 않았습니다.

## 실행
`fruit-loft.html`을 다운로드해 브라우저로 열면 됩니다. 서버·설치·인터넷 연결 불필요.

## 조작과 규칙
- ← → 또는 A D: 이동. ↑ ↓ 또는 W S: 사다리. Space: 점프. P: 일시정지.
- 화면 방향 버튼: 한 번 누르면 계속 걷기, 같은 방향 재클릭 또는 ■로 정지.
- 3개 창고, 창고별 과일12개, 과일당100점, 기회3번.
- 사다리 중심 25px 안에서 위/아래를 누르면 자동으로 층을 이동합니다.
- 적은 점프로 피합니다. 피격시 출발점 복귀, 모은 과일 유지, 이동입력 초기화, 1.8초 보호.
- 창 전환시 자동일시정지. 저장/랭킹/온라인기능 없음.

## 개발과 테스트
`engine.js`: 규칙/물리. `app.js`: 렌더링/입력. `index.html`: 템플릿.
`python3 build.py`로 단일 HTML 생성. `node --test tests/engine.test.js`로 16개 검사.
브라우저에서 첫창고 과일3→피격→3개/300점유지/자동걷기정지, 사다리2층이동→4개/400점, 점프, 일시정지/재시작 확인. 390px 가로넘침 없음. 720px높이에서 버튼 표시 확인.
전체창고 수동완주나 장시간 밸런스는 미검증. 전체과일/클리어검사는 합성상태를 이용한 규칙검사이며 수동공략이 아닙니다.
표지 WebP는 생성 일러스트, 나머지 WebP는 실제 브라우저 화면입니다.
