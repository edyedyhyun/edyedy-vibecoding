# 톡! 나누기 / Split Pop

큰 공을 둘로 나누며 피하는 오리지널 HTML5 아케이드 게임입니다. 원작 캐릭터·배경·음원은 사용하지 않았습니다.

## 실행
`split-pop.html`을 내려받아 브라우저로 열면 됩니다. 인터넷 연결, 설치, 서버가 필요 없습니다.

- 좌우 방향키 / A D: 이동
- Space: 발사 (길게 누르면 연속 발사)
- P: 일시정지/계속
- 화면 버튼도 길게 누를 수 있습니다.
- 3라운드, 기회 3번. 큰 공 → 중간 공 2개 → 작은 공 4개, 작은 공은 맞히면 사라집니다.
- 피격 후 1.8초 보호. 다른 창으로 전환하면 자동 일시정지됩니다.

## 개발
`engine.js`는 물리/판정, `app.js`는 화면/입력, `index.html`은 템플릿입니다.
수정 후 `python3 build.py`로 단일 HTML을 다시 만듭니다.
테스트: `node --test tests/engine.test.js` (15개)

## 검증 범위
브라우저에서 실제 발사, 공 분열, 피격, 1라운드 1700점 클리어(기회1), 2라운드 점수/기회 유지, 일시정지/계속, 재시작 확인. 390px 화면 가로 넘침 없음. 전체 3라운드 수동 완주는 검증하지 않았습니다.
`images/cover.webp`는 생성 일러스트이고 나머지 WebP는 실제 게임 화면 캡처입니다.
