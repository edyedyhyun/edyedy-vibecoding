# 구름길 · Cloud Trail

작은 발판과 틈을 넘어 도착 깃발로 가는 오프라인 HTML5 게임입니다. 원작 캐릭터나 에셋을 사용하지 않은 짧은 플랫폼 코스입니다.

## 실행
`cloud-trail.html`을 내려받아 브라우저에서 여세요. 인터넷이나 설치가 필요하지 않습니다.

- 좌우 방향키: 이동
- 위 방향키 또는 Space: 점프
- P: 일시정지
- 화면 버튼: 이동·점프
- 별은 선택 사항입니다. 떨어지면 중간 깃발 또는 출발점으로 돌아오며 얻은 별은 유지됩니다.

## 개발
`engine.js`: 고정 시간 간격 물리·충돌·점프 입력·체크포인트
`app.js`: Canvas 그림과 입력
`index.html`: 편집용 화면
`python3 build.py`: 단일 HTML 생성
`node --test tests/engine.test.js`: 물리 및 상태 테스트

초기 점프 설정은 96px 첫 발판을 넘지 못했습니다. 점프 속도와 중력을 조절했고, 발판 끝 90ms와 착지 입력 120ms의 여유를 추가했습니다. 플레이 중 두 번 떨어진 뒤 틈을 140px에서 90px로 줄였습니다.

`images/`의 WebP는 블로그용입니다. cover는 생성 일러스트이며 나머지는 수정 과정의 실제 캡처입니다. 캡처의 틈 간격은 최종판과 다릅니다. 한 코스만 제공하며 적·소리·여러 스테이지는 없습니다.
