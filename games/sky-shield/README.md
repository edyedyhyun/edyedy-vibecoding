# 먼저 도착할 빛 / Sky Shield

미사일 커맨드풍의 오리지널 HTML5 방어 게임. 원작 이미지·음원·맵을 사용하지 않았습니다.

## 실행 및 조작
`sky-shield.html` 한 파일을 내려받아 브라우저로 엽니다. 설치·서버·인터넷 연결 불필요.
게임판을 클릭/터치하면 해당 지점(상단 y24~350 제한)으로 중앙 발사대의 방어탄이 이동하고 도착 지점에서 폭발합니다.
1·2·3 또는 상공 버튼은 x80/320/560,y250의 미리 정한 조준점. P 일시정지, 창 전환 자동 정지.

## 규칙
방어탄220px/s, 폭발 반경58px: .55초 확장 후1.05초 축소. 격파된 미사일은 반경32px의 추가 폭발을 남깁니다. 격파100점.
기지3곳, 차례마다18발. 첫 차례6발/55px/s, 다음8발/67px/s, 마지막10발/79px/s. 첫차례수직낙하, 이후비스듬한궤적.
기지를 모두 잃으면 종료. 남은 기지가 있고 예정된 미사일을 모두 처리하면 다음차례. 기지피해/점수/격파수 유지, 탄18발보충. 세차례후완료.

## 개발 및 검증
`python3 build.py`는 index.html/engine.js/app.js를 한파일로 묶습니다.
`node --test tests/engine.test.js`:13개 통과. 합성 동일장면에서 현재점aim는0격파, 미래점aim는1격파 비교. 폭발/연쇄/여러적동시격파/탄수/피해/다음차례 검사.
실제브라우저 첫적현재점발사→0점/17탄/0방어; 재시작뒤더아래y250발사→100점/17탄/1방어. 이후화면DOM과버튼자동조작으로첫차례6방어/600점/3기지/11탄완료. 차례2에서600점과기지유지/18탄보충 확인. 일시정지와390px가로넘침없음 확인.
전체세차례직접완주/실제휴대폰터치/장시간난이도는미검증. images/cover는생성표지,나머지WebP는실제브라우저캡처.
