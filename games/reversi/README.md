# 뒤집는 한 수

오델로 · 로컬 2인용

순수 HTML5/CSS/JavaScript로 만든 오프라인 2인용 리버시(오델로) 게임입니다. 외부 라이브러리나 네트워크 요청 없이 브라우저만 있으면 실행됩니다.

## 실행 방법

- 개발용: `index.html`을 브라우저로 열면 됩니다 (`engine.js`, `app.js`가 같은 폴더에 있어야 합니다).
- 배포용 단일 파일: `python3 build.py`를 실행하면 `reversi.html` 하나로 합쳐진 자족형 파일이 생성됩니다. 이 파일만 공유해도 그대로 동작합니다.

## 규칙 요약

- 8x8 보드, 흑이 먼저 둡니다.
- 초기 배치: 백돌 D4·E5, 흑돌 D5·E4.
- 상대 돌을 자신의 돌 사이에 끼우면(8방향 직선 연속) 그 사이의 상대 돌이 모두 뒤집힙니다.
- 최소 한 개 이상 뒤집을 수 있는 칸에만 둘 수 있습니다.
- 둘 곳이 없으면 자동으로 차례가 넘어가며 화면에 안내 문구가 표시됩니다.
- 양쪽 모두 둘 곳이 없으면 게임이 종료되고, 돌 개수가 많은 쪽이 승리합니다(동률은 무승부).

## 구성 파일

- `engine.js` — 순수 게임 로직 (CommonJS / `window.ReversiEngine` 겸용, DOM 의존 없음).
- `app.js` — 화면 렌더링, 키보드/마우스 조작, 다이얼로그 등 UI 로직.
- `index.html` — 마크업과 인라인 CSS.
- `build.py` — 위 세 파일을 하나의 `reversi.html`로 합치는 빌드 스크립트.

## 조작

- 마우스: 칸을 클릭해 착수.
- 키보드: 방향키로 칸 이동(로빙 tabindex), Enter/Space로 착수.
- "둘 수 있는 자리 표시" 체크박스로 힌트 점 표시를 끌 수 있습니다(기본 켜짐).
- "한 수 무르기"로 직전 한 수를 되돌릴 수 있습니다(자동 패스·종료 상태 포함 전체 복원).
- "새 게임"은 진행 중인 판이 있으면 커스텀 확인 대화상자를 띄웁니다(브라우저 기본 confirm 미사용).

이 게임은 AI나 타이머 없이 두 사람이 한 화면에서 번갈아 두는 로컬 2인용 전용입니다.
