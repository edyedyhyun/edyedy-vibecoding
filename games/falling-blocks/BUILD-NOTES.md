# BUILD-NOTES

실제로 내린 설계 결정만 기록합니다.

- **엔진/렌더 분리**: `engine.js`는 DOM을 전혀 참조하지 않는 순수 함수 모음으로
  작성해 CommonJS(`module.exports`)와 `window.BlockEngine` 양쪽에서 그대로
  재사용되게 했습니다. 이렇게 해야 검토자가 별도 테스트 러너에서 `require`로
  바로 물리/충돌 로직을 확인할 수 있습니다.
- **시드 PRNG는 mulberry32**: 표준 라이브러리 없이 짧은 코드로 결정적 난수를
  얻을 수 있어 선택했습니다. `rngState`를 state에 그대로 저장해 상태 자체가
  재생 가능한 스냅샷이 되도록 했습니다.
- **7-bag은 3개 이상 항상 미리 채움**: `bagQueue`가 3개 미만이 되면 새 bag을
  이어 붙여 `next` 미리보기가 항상 3개를 보장하도록 했습니다.
- **회전 킥은 의도적으로 단순화**: 전체 SRS 킥 테이블 대신 좌우 소폭 오프셋 +
  위로 한 칸만 시도하는 축소판을 구현했습니다(README에 명시). 요구사항이
  "완전한 SRS를 주장하지 말 것"이었기 때문에 과도한 복잡도를 피했습니다.
- **락 지연은 이동/회전 성공 시에만 리셋, 실패한 킥은 리셋하지 않음**:
  `registerMovementResetsLockDelay`가 실제로 위치가 바뀐 뒤에만 호출되므로,
  제자리에서 눌러도 움직이지 않는 입력은 리셋 횟수를 소모하지 않습니다.
  대신 실제로 화면이 바뀌는 입력만 최대 15회로 제한해 무한 정지를 막았습니다.
- **고스트는 `landingY()` 재사용**: 하드 드롭과 고스트 렌더링이 동일한 충돌
  계산 경로를 쓰도록 해서 시각적 착지 위치와 실제 드롭 결과가 어긋나지
  않게 했습니다.
- **접근성 텍스트는 값 변경 시에만 갱신**: `app.js`의 `lastRender` 캐시로
  점수/줄/상태/다음 블록 텍스트를 매 프레임 다시 쓰지 않고 값이 실제로
  바뀔 때만 갱신해, 스크린 리더가 매 프레임 알림받지 않도록 했습니다.
- **키보드 이벤트에서 `preventDefault` 우선 호출**: Space/화살표가 스크롤을
  유발하지 않게 하는 동시에, 버튼에 포커스가 있는 상태에서 Space를 눌러도
  브라우저 기본 버튼 클릭이 발생하지 않아 조작이 중복 처리되지 않습니다.
- **블러/숨김 시 자동 일시정지, 재개는 항상 수동**: 탭 전환/최소화 중 쌓인
  키 입력이 복귀 시 갑자기 반영되는 것을 막기 위해 DAS 상태와 소프트드롭
  플래그를 함께 초기화합니다. 사용자가 P 또는 버튼을 눌러야만 재개됩니다.
- **보드는 캔버스, 상태 텍스트는 별도 DOM**: 매 프레임 다시 그려야 하는
  시각 요소(보드/다음 블록 미리보기)와 드물게 바뀌는 접근성 텍스트를
  구조적으로 분리했습니다.
- **build.py는 표준 라이브러리만 사용**: `<script src="...">` 두 줄을
  정규식으로 찾아 파일 내용으로 치환하는 최소 스크립트로, 정확히 한 번씩
  일치하지 않으면 에러를 내어 번들 누락을 조기에 발견하게 했습니다.
