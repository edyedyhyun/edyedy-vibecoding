# 한푼부터 부자까지

하나의 게임을 클릭 프로토타입에서 공개 가능한 방치형 웹 게임으로 발전시키는 연재 프로젝트입니다. 현재는 제작기 01, **v0.2.0**입니다.

## 현재 버전 실행

`one-coin-life.html`을 내려받아 브라우저에서 여세요. 설치, 외부 라이브러리, 인터넷 연결 없이 실행할 수 있는 단일 파일입니다.

분리된 소스를 확인하려면:

```sh
git clone --depth 1 --branch one-coin-life-ep02 https://github.com/edyedyhyun/edyedy-vibecoding.git one-coin-life-ep02
cd one-coin-life-ep02/games/one-coin-life
python3 -m http.server 8000
```

Windows에서 Python 명령이 `python`이라면 마지막 명령의 `python3`를 `python`으로 바꾸세요. 브라우저에서 `http://localhost:8000`을 엽니다. 이후 편의 코드가 달라져도 `one-coin-life-ep02` 태그에서 이 편의 상태를 그대로 받을 수 있습니다.

## 제작기 01의 기능

- 작은 일 버튼 한 번에 1원과 작업 횟수 1회가 증가합니다.
- 첫 100원 목표, 남은 금액, 달성 표시가 있습니다.
- 달성 뒤에도 계속 입력할 수 있습니다.
- 버튼에 포커스를 두고 Enter/Space로 조작할 수 있습니다.
- 다시 시작 버튼으로 0원으로 돌아갑니다.
- 390px 화면에서 가로 넘침 없이 배치됩니다.

**아직 자동 수입, 강화, 저장, 로그인 기능이 없습니다. 새로고침하면 0원으로 돌아갑니다.** 이 버전은 방치형 게임의 첫 화면을 만드는 단계이며, 서비스 완성판이 아닙니다. 금액은 게임 안의 가상 재화입니다.

## 직접 확인할 순서

1. 처음 화면에 0원과 0회가 보이는지 확인합니다.
2. 버튼을 17회 입력합니다. 17원, 17회, 83원 남음이 표시됩니다.
3. 100회까지 입력합니다. 100원과 첫 목표 달성이 표시됩니다.
4. 한 번 더 입력합니다. 101원으로 증가하고 목표 달성 표시는 유지됩니다.
5. 다시 시작을 누르고, 버튼을 선택한 뒤 Space와 Enter를 한 번씩 누릅니다. 2원이 됩니다.
6. 새로고침합니다. 저장 기능이 없으므로 다시 0원입니다.

브라우저 UI로 위 항목을 확인했습니다. 390px 화면 배치와 62px 주요 버튼 높이도 확인했습니다. 실제 휴대폰에서의 터치 체감과 긴 플레이의 성장 속도는 아직 검증하지 않았습니다.

## 소스 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면과 작은 방 SVG |
| `styles.css` | 데스크톱·모바일 배치, 클릭 피드백 |
| `app.js` | 클릭 수입, 목표 달성, 초기화 |
| `build.py` | CSS와 JS를 단일 파일로 묶는 Python 3 스크립트 |
| `one-coin-life.html` | 바로 실행하는 단일 HTML |
| `images/ep01/` | 표지와 실제 검증 화면 WebP |

소스를 바꾼 뒤 단일 파일을 다시 만들려면:

```sh
python3 build.py
```

캐릭터와 방은 이 프로젝트에서 SVG로 직접 그렸습니다. 표지는 별도로 생성한 컨셉 이미지이며 현재 플레이 화면과 구분합니다.

전체 진행 순서는 [연재 계획](ROADMAP.md)을 참고하세요.

## 제작기 2: 클릭 반응

- 클릭 위치에서 +1원과 원형 효과, 잔액 강조와 캐릭터 반응. 키보드는 버튼 중앙 기준.
- 효과를 꺼도 수입과 작업 횟수는 동일. OS 동작 줄이기 설정에서는 이동 효과 생략.
- 수입은 네이티브 click 하나에서만 처리. pointerdown/touchend에 수입을 중복 등록하지 않음.
- Enter/Space 자동 반복 keydown 방지. 수동으로 다시 누르는 입력은 허용.
- 동시 효과 요소 최대 12개. 효과는 animationend에서 제거.
- 목표 달성 안내, 입력 상태의 지연된 접근성 안내. 저장·강화·자동 수입은 아직 없음.
- 검증: `node tests/input-feedback.test.cjs` (Node가 있을 때), 브라우저 클릭·Enter·Space·효과 끄기·목표·재시작·390px 레이아웃. 실제 휴대폰 터치는 아직 미검증.
