# 한푼부터 부자까지

하나의 게임을 클릭 프로토타입에서 공개 가능한 방치형 웹 게임으로 발전시키는 연재 프로젝트입니다. 현재는 제작기 06, **v0.6.0**입니다.

## 현재 버전 실행

`one-coin-life.html`을 내려받아 브라우저에서 여세요. 설치, 외부 라이브러리, 인터넷 연결 없이 실행할 수 있는 단일 파일입니다.

분리된 소스를 확인하려면:

```sh
git clone --depth 1 --branch one-coin-life-ep06 https://github.com/edyedyhyun/edyedy-vibecoding.git one-coin-life-ep06
cd one-coin-life-ep06/games/one-coin-life
python3 -m http.server 8000
```

Windows에서 Python 명령이 `python`이라면 마지막 명령의 `python3`를 `python`으로 바꾸세요. 브라우저에서 `http://localhost:8000`을 엽니다. 이후 편의 코드가 달라져도 `one-coin-life-ep06` 태그에서 이 편의 상태를 그대로 받을 수 있습니다.

## 제작기 01의 기능

- 작은 일 버튼 한 번에 1원과 작업 횟수 1회가 증가합니다.
- 첫 100원 목표, 남은 금액, 달성 표시가 있습니다.
- 달성 뒤에도 계속 입력할 수 있습니다.
- 버튼에 포커스를 두고 Enter/Space로 조작할 수 있습니다.
- 다시 시작 버튼으로 0원으로 돌아갑니다.
- 390px 화면에서 가로 넘침 없이 배치됩니다.

**작업 도구·첫 직원·브라우저 자동 저장이 있습니다. 로그인·오프라인 보상은 아직 없습니다. 저장이 허용된 같은 브라우저와 주소에서 진행을 이어갑니다.** 이 버전은 방치형 게임의 첫 화면을 만드는 단계이며, 서비스 완성판이 아닙니다. 금액은 게임 안의 가상 재화입니다.

## 직접 확인할 순서

1. 처음 화면에 0원과 0회가 보이는지 확인합니다.
2. 버튼을 17회 입력합니다. 17원, 17회, 83원 남음이 표시됩니다.
3. 100회까지 입력합니다. 100원과 첫 목표 달성이 표시됩니다.
4. 한 번 더 입력합니다. 101원으로 증가하고 목표 달성 표시는 유지됩니다.
5. 다시 시작을 누르고, 버튼을 선택한 뒤 Space와 Enter를 한 번씩 누릅니다. 2원이 됩니다.
6. 새로고침합니다. 저장 기능이 없으므로 다시 0원입니다.

브라우저 UI로 위 항목을 확인했습니다. 390px 화면 배치와 62px 주요 버튼 높이도 확인했습니다. 실제 휴대폰에서의 터치 체감과 긴 플레이의 성장 속도는 아직 검증하지 않았습니다.

전체 진행 순서는 [연재 계획](ROADMAP.md)을 참고하세요.

## 제작기 2: 클릭 반응

- 클릭 위치에서 +1원과 원형 효과, 잔액 강조와 캐릭터 반응. 키보드는 버튼 중앙 기준.
- 효과를 꺼도 수입과 작업 횟수는 동일. OS 동작 줄이기 설정에서는 이동 효과 생략.
- 수입은 네이티브 click 하나에서만 처리. pointerdown/touchend에 수입을 중복 등록하지 않음.
- Enter/Space 자동 반복 keydown 방지. 수동으로 다시 누르는 입력은 허용.
- 동시 효과 요소 최대 12개. 효과는 animationend에서 제거.
- 목표 달성 안내, 입력 상태의 지연된 접근성 안내. 저장·강화·자동 수입은 아직 없음.
- 검증: `node tests/input-feedback.test.cjs` (Node가 있을 때), 브라우저 클릭·Enter·Space·효과 끄기·목표·재시작·390px 레이아웃. 실제 휴대폰 터치는 아직 미검증.

## 제작기 3: 계산과 화면 분리

`economy.js`는 순수 계산 규칙입니다. `initialState()`, `earn(state)`, `goalView(state)`를 제공하며 DOM·타이머·저장소를 읽지 않습니다. earn은 이전 상태를 수정하지 않고 새 상태, 실제 지급액, 목표 도달 여부를 반환합니다. `app.js`는 입력과 렌더링·효과를 담당합니다. 브라우저 로컬 규칙이며 서버 검증이나 조작 방지를 구현한 것은 아닙니다.

검증: `node tests/economy.test.cjs` (10개), `node tests/input-feedback.test.cjs` (이전 입력 계약). Node 없이도 로컬 서버에서 `checks.html`을 열어 검증 버튼을 누를 수 있습니다. 단일 HTML 다운로드에는 검증 화면이 아닌 게임 자체가 포함됩니다.

이전 버전은 태그 `one-coin-life-ep01-design`, `one-coin-life-ep02`에서 받을 수 있습니다. 강화·자동 수입·저장은 후속 회차입니다.

## 제작기 4: 첫 작업 도구

50원짜리 작업 도구를 한 번 사면 작업당 수입이 1원에서 2원으로 증가합니다. 미보유·잔액49원 이하는 구매 불가. 구매 후 재구매와 추가 차감은 없습니다. 목표는 누적 수입100원이며 보유금과 구분합니다. totalEarned는 수입에만 증가하고 구매시 유지합니다. reset/reload는 도구까지 초기화합니다. 저장·자동수입은 아직 없습니다.

검증 18개: node tests/economy.test.cjs 및 브라우저 checks.html. 입력/구매 연동: node tests/input-feedback.test.cjs. 실제 브라우저49→50→구매0→1회2원→총75회/보유50/누적100,모바일390px폭 확인. 실제휴대폰터치미검증. 이전 태그 one-coin-life-ep03은3편 상태를 보존합니다.

## 제작기 5: 첫 직원과 자동 수입

- 100원에 직원 1명을 한 번 고용. 화면이 보이는 동안 초당 1원, 회수에 100초가 필요한 첫 기준값입니다. 장기 밸런스 검증은 아직입니다.
- 직접 번 돈/직원이 번 돈/보유금/누적 수입 구분. 자동 수입은 작업 횟수를 늘리지 않습니다.
- performance.now()의 경과 시간을 계산하고 1초 미만의 나머지 시간을 보존합니다. 콜백 횟수를 돈으로 사용하지 않습니다.
- visibilitychange와 BFCache 복귀 때 시간을 다시 잡습니다. 다른 탭·창 닫힘 동안 보상은 제공하지 않습니다. 브라우저가 visible로 보고하는 화면에 한합니다.
- 타이머는 앱 시작 때 하나만 생성합니다. 재고용/리셋 때 추가하지 않습니다.
- 새로고침/리셋은 직원과 재화를 초기화합니다. 서버 검증이나 서비스 완성판은 아닙니다.

검증: `node tests/economy.test.cjs` 30개, `node tests/input-feedback.test.cjs`, `node tests/worker-timing.test.cjs`. 지연/숨김·복귀/BFCache/리셋은 가상 시계로 확인. 브라우저에서 99원 고용 불가→100원 고용→0원→클릭 없이 직원 25원·작업100회·누적125원을 실제 확인했습니다. IAB는 여러 탭을 visible로 보고하므로 실제 숨김 동작·실제 휴대폰은 미검증입니다.

제작기 4는 `one-coin-life-ep04`, 5편은 `one-coin-life-ep05`, 현재6편은 `one-coin-life-ep06` 태그로 보존합니다.

## 제작기 6: 저장과 불러오기

`save.js`가 저장 경계를 맡습니다. `one-coin-life.save` 키에 `{version:1,savedAt,state}`를 JSON으로 기록합니다. 보유금/작업횟수/누적수입/도구/직원/직원수입/1초 미만 근무시간을 저장하고, 클릭·구매·고용·직원수입·페이지이탈 때 갱신합니다. 화면을 읽거나 그리는 코드는 저장 형식과 분리했습니다.

- 최초 시작 시 읽고 검증합니다. 금액/횟수는 0 이상의 안전 정수, 보유 여부는 boolean, 지출은 실제 구매 합계와 일치해야 합니다. 알려진 필드만 가져옵니다. 이 검사는 조작 방지나 서버 검증이 아닙니다.
- 깨진 JSON/불일치/다른 버전은 기존 문자열을 보존하고 자동 저장을 중지합니다. 확인 대화상자로 해당 게임 키를 지운 뒤 새로 시작할 수 있습니다. 다른 사이트 데이터는 지우지 않습니다.
- 저장소 예외는 화면에 실패로 표시하며 메모리 플레이를 허용합니다. 삭제 실패 때에는 기존 진행도 초기화하지 않습니다.
- `savedAt`은 기록 정보일 뿐 오프라인 보상에 사용하지 않습니다. 로드 시 타이머 기준은 현재 시점으로 시작합니다.
- 한 창에서 실행하세요. 여러 탭의 저장 충돌 조정, 계정 동기화, 클라우드 백업은 후속 작업입니다. 브라우저 데이터 삭제/시크릿 모드 종료로 기록을 잃을 수 있습니다.

### 저장 검증을 위한 로컬 실행

HTML 파일을 직접 여는 `file:` 주소의 localStorage 동작은 브라우저마다 보장되지 않습니다([MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)). 파일 이동이나 브라우저 변경도 같은 기록을 뜻하지 않습니다. 진행 보존을 확인하려면 위 Python 서버 방법으로 실행한 뒤 **같은 http://localhost:8000 주소**로 다시 접속하세요. `localhost`와 `127.0.0.1`, 다른 포트·브라우저는 서로 다른 저장 영역입니다. 단일 `one-coin-life.html`도 이 서버에서 열 수 있고 외부 인터넷 연결은 필요하지 않습니다.

### 검증

`node tests/save.test.cjs` 저장 규칙14조건, `node tests/save-app.test.cjs` 실제앱연동, 기존계산30조건·입력·타이머테스트를 통과했습니다. 저장소 접근/쓰기/삭제 실패는 테스트 대역으로 재현했습니다. 브라우저에서는17원/17회새로고침보존,도구·직원·누적150/작업100복원,깨진JSON보존과미지원버전차단,초기화취소/확정확인했습니다. `tests/save-fixture.html`은 **고의로 게임 기록을 교체**하는개발용화면이므로실제진행을보관한브라우저에서사용하지마세요. 실제휴대폰/여러탭충돌은미검증입니다.
