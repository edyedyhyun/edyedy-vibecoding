# 한푼부터 부자까지 연재 계획

독자가 각 편의 코드를 실행하고 확인하면서 하나의 방치형 클리커 웹 게임을 공개하고 운영하는 것이 목표입니다. 첫 편은 실행 가능한 시작 화면이고, 이후 편에서 같은 프로젝트를 계속 확장합니다. 아직 구현하지 않은 항목은 아래의 계획이며 완성된 기능이 아닙니다.

| 편 | 내용 | 확인할 결과 |
| --- | --- | --- |
| 01 | 기획과 첫 클릭 화면 | 0원에서 시작해 100원 목표에 도달하는 v0.1.0 |
| 02 | 클릭 입력과 피드백 다듬기 | 마우스·키보드·터치 입력의 반응과 조작 흐름 |
| 03 | 성장 계산과 화면 분리 | 계산 코드의 독립 실행과 오류 검증 |
| 04 | 강화와 구매 | 잔액 부족·중복 구매·강화 비용 처리 |
| 05 | 동료와 자동 수입 | 고용·강화·시간에 따른 수입 |
| 06 | 성장 속도와 큰 숫자 | 초반 대기 시간, 수입 대비 가격, 큰 금액 처리 |
| 07 | 시각적 성장 | 캐릭터·방·작업 공간의 단계별 변화 |
| 08 | 로컬 저장과 복구 | 새로고침, 저장 형식 이전, 내보내기·불러오기 |
| 09 | 오프라인 보상 | 복귀 시 시간 차 계산, 상한, 시계 변경 처리 |
| 10 | 목표와 장기 성장 | 해금·업적, 환생 도입 여부와 보상 |
| 11 | 모바일·접근성·성능 | 실제 기기 조작과 렌더링 확인 |
| 12 | 서버 경제와 데이터베이스 | 서버가 계산하는 재화·보상과 저장 구조 |
| 13 | 로그인과 클라우드 저장 | 여러 기기, 충돌, 연결 실패와 복구 |
| 14 | 조작과 동시 요청 대응 | 사용자별 권한, 요청 검증, 보상 중복과 동시 구매 |
| 15 | 웹 배포 | 개발·운영 분리, HTTPS 주소, 자동 배포와 되돌리기 |
| 16 | PWA와 업데이트 | 설치, 캐시 갱신, 버전 호환 |
| 17 | 베타 테스트 | 플레이 의견, 오류 기록, 성장 속도 조정 |
| 18 | 공개와 운영 | 출시 점검, 복구, 문의 창구, 첫 운영 업데이트 |

진행 중 실험이 길어지면 별도 편으로 나눌 수 있습니다. 각 편에는 소스 버전 태그, 실행 방법, 실제 화면과 검증 결과를 남깁니다. 서버·호스팅 서비스와 비용은 해당 단계에서 선정하고 문서화합니다.

## 진행 기록

- 01: 로컬 프로토타입 완성. 자동 수입과 저장은 아직 없음.
- 02 이후: 예정.

오프라인 보상은 닫힌 브라우저가 계속 작동하는 방식이 아니라, 복귀 시 경과 시간을 계산하는 방식으로 다룹니다. 서버 단계에서는 클라이언트가 보낸 잔액과 시간을 그대로 신뢰하지 않도록 설계를 확장합니다.
