# 당겨봐! · Pocket Sling

주황 공을 당겼다 놓아 상자를 밀고 민트 표적을 맞히는 3스테이지 HTML5 게임입니다. 기존 작품의 캐릭터/이미지/음원을 사용하지 않았습니다.

## 실행과 조작

`slingshot.html`을 다운로드해 브라우저로 열면 됩니다. 물리 라이브러리까지 파일 안에 포함되어 있어 다운로드 후에는 인터넷이나 서버가 필요 없습니다.

- 주황 공 주변을 잡아 왼쪽 아래로 드래그한 뒤 놓으면 발사합니다.
- 각도(5~75도)와 힘(20~100%) 슬라이더 + 공 발사 버튼으로도 조작할 수 있습니다.
- Space 발사, P 일시정지/이어하기, R 현재 판 초기화. 슬라이더/버튼에 포커스가 있으면 해당 컨트롤의 기본 키 동작을 우선합니다.
- 판마다 공 3개. 표적을 모두 맞히면 다음 판으로 이동합니다. 상자에 의한 간접 충돌과 표적의 화면 이탈도 성공 판정에 포함합니다.
- 예상 궤적은 현재 장애물에 처음 부딪히기 전까지의 예측입니다. 상자가 움직인 뒤의 연쇄 반응은 예측하지 않습니다.
- 탭/창을 떠나면 진행 중인 게임이 자동으로 멈춥니다.

## 구성

- `engine.js`: Matter.js 기반 고정 시간 간격(120Hz) 물리, 충돌/기회/스테이지 규칙, 궤적 예측
- `app.js`: Canvas 렌더링, 포인터/키보드 입력, 반응형 조작 UI
- `index.html`: 개발용 페이지
- `slingshot.html`: 라이브러리/스타일/코드를 포함한 오프라인 실행 파일
- `build.py`: `python3 games/slingshot/build.py`로 실행 파일 재생성
- `engine.test.js`: `node --test games/slingshot/engine.test.js`
- `tests/mobile-preview.html`: 390px iframe을 이용한 반응형 배치 확인용 페이지
- `vendor/matter.min.js`: Matter.js 0.20.0. MIT, 라이선스는 `vendor/LICENSE-Matter.txt` 및 배포 파일 상단에 보존
- `images`: 블로그용 WebP 표지와 실제 실행 캡처

Matter.js 공식 문서: https://brm.io/matter-js/docs/
배포 출처: https://cdn.jsdelivr.net/npm/matter-js@0.20.0/build/matter.min.js

## 검증 기록 (2026-09-30)

12개 엔진 테스트 통과. 첫 판 25도/75% 실패 후 같은 각도/60% 성공을 실제 UI에서 확인했습니다. 수정 후 1판 25도/60%, 2판 15도/65%, 3판 드래그(25도/60%)로 세 판 완료를 확인했습니다. 2·3판 조합은 엔진 탐색 결과도 참고했습니다. 공 발사/드래그, 궤적 토글, 판 이동/처음부터 다시, 일시정지/이어하기를 확인했습니다. 390px iframe에서 가로 넘침 없이 발사 버튼 하단577px를 확인했습니다. 실제 휴대폰 터치와 장시간 난이도 밸런스는 미검증입니다.

초기 화면은 720px 높이에서 조작부가 화면 아래로 밀렸고, 게임판 높이를 제한했습니다. 초기 궤적은 장애물 없이 계속 그려졌지만 최종판은 첫 충돌에서 끊습니다. 최초 명중 순간 즉시 정지하던 결과 화면은 1초 더 물리 계산 후 표시하도록 조정했습니다.

## 표지 생성

내장 image_gen 도구 사용. `images/cover.webp`는 일러스트이며 실제 게임 화면이 아닙니다. 프롬프트는 `cover-prompt.txt`에 기록했습니다. 나머지 WebP는 실제 브라우저 캡처를 변환한 것입니다.
