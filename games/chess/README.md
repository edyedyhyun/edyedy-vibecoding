# 다음 한 수

체스 · 로컬 2인용

순수 HTML5/CSS/JavaScript로 만든 오프라인 2인용 체스 게임입니다. 외부 라이브러리나 네트워크 요청 없이 브라우저만 있으면 실행됩니다. CPU 대전이나 타이머는 없으며, 한 화면에서 두 사람이 번갈아 둡니다.

## 실행 방법

- 개발용: `index.html`을 브라우저로 열면 됩니다 (`engine.js`, `app.js`가 같은 폴더에 있어야 합니다).
- 배포용 단일 파일: `python3 build.py`를 실행하면 `chess.html` 하나로 합쳐진 자족형 파일이 생성됩니다. 이 파일만 공유해도 그대로 동작합니다.

## 규칙 요약

- 8x8 보드, 백이 먼저 둡니다.
- 모든 기물의 정식 이동 규칙을 구현: 폰(첫 이동 2칸, 대각선 포획, 앙파상, 프로모션), 나이트, 비숍, 룩, 퀸, 킹.
- 자신의 킹이 체크에 노출되는 수는 둘 수 없습니다(핀 포함).
- 캐슬링: 킹과 해당 룩이 한 번도 움직이지 않았고, 사이 칸이 비어 있으며, 킹이 체크 상태가 아니고, 이동 경로(통과 칸 포함) 어디에서도 체크되지 않을 때만 가능합니다.
- 앙파상: 상대 폰이 방금 두 칸 전진했을 때, 바로 다음 수에서만, 자신의 킹이 안전한 경우에만 가능합니다.
- 프로모션: 폰이 마지막 랭크에 도달하면 반드시 퀸/룩/비숍/나이트 중 하나를 직접 선택해야 합니다(자동 퀸 승진 없음). 선택 전에는 게임 상태가 변경되지 않습니다.
- 체크메이트/스테일메이트를 자동 판정합니다.
- 무승부:
  - **자동**: 기물 부족(킹 vs 킹, 킹+비숍 vs 킹, 킹+나이트 vs 킹, 킹 이외의 기물이 모두 같은 색 칸 비숍인 경우), 75수 규칙, 5회 동형 반복.
  - **선언 가능**: 50수 규칙과 3회 동형 반복은 조건 충족 시 버튼으로 직접 선언해야 합니다(자동 종료되지 않음).
- 킹은 결코 포획되지 않습니다 — 체크메이트가 되면 그 전에 게임이 종료됩니다.

## 구성 파일

- `engine.js` — 순수 게임 로직 (CommonJS / `window.ChessEngine` 겸용, DOM 의존 없음). 파일 상단 주석에 상태 구조와 공개 API가 문서화되어 있습니다.
- `app.js` — 화면 렌더링, 키보드/마우스 조작, 프로모션·새 게임 다이얼로그 등 UI 로직.
- `index.html` — 마크업과 인라인 CSS.
- `build.py` — 위 세 파일을 하나의 `chess.html`로 합치는 빌드 스크립트.

## 엔진 API 요약

```
createState()                       // 초기 상태 생성
loadFEN(fen)                        // FEN 문자열로 상태 생성 (테스트/디버깅용)
legalMoves(state, from?)            // from 생략 시 현재 차례의 전체 합법수, 지정 시 해당 칸의 합법수
play(state, from, to, promotion?)   // 착수. 프로모션이 필요한데 promotion 누락 시 false만 반환하고 상태는 변하지 않음
undo(state)                         // 직전 수/무승부 선언을 포함해 한 단계 되돌림
status(state)                       // 턴, 상태, 승자, 체크 여부, 무승부 선언 가능 여부 등 요약
claimDraw(state, 'fifty'|'threefold') // 조건 충족 시 무승부 선언
isAttacked(board, square, byColor)  // 합법수 생성과 독립적인 공격 판정
findKing(board, color)              // 해당 색 킹의 위치
toFEN(state)                        // 현재 상태를 FEN 문자열로 변환
```

상세 필드 설명은 `engine.js` 상단 주석을 참고하세요.

## 조작

- 마우스: 기물을 클릭해 선택하고, 강조된 칸(점: 이동 가능, 테두리: 포획 가능)을 클릭해 착수.
- 같은 편 기물을 다시 클릭하면 선택이 그 기물로 전환됩니다.
- 키보드: 방향키로 칸 이동(로빙 tabindex), Enter/Space로 선택·착수.
- "한 수 무르기"로 직전 한 수를 되돌립니다(캐슬링 권리·앙파상·기보 등 전체 상태 복원).
- "보드 뒤집기"로 시점을 백/흑 기준으로 전환할 수 있습니다.
- 프로모션이 필요한 수를 두면 모달에서 퀸/룩/비숍/나이트를 직접 선택해야 합니다.
- 50수 규칙·3회 동형 반복 조건이 충족되면 전용 버튼이 나타나 직접 무승부를 선언할 수 있습니다.
- "새 게임"은 진행 중인 판이 있으면 커스텀 확인 대화상자를 띄웁니다(브라우저 기본 confirm 미사용).

이 게임은 AI나 타이머 없이 두 사람이 한 화면에서 번갈아 두는 로컬 2인용 전용입니다.

## 검증과 범위

`node --test games/chess/test-engine.js` — 13개 테스트. 초기 이동 트리 20/400/8902, 특수 이동과 무르기, 종료 및 반복 판정 포함. 별도의 python-chess와 1,080개 배치의 합법수를 비교해 일치했습니다.

브라우저에서 나이트 안내, 캐슬링, 체크메이트와 무르기, 나이트 승격, 보드 뒤집기, 320px 폭 가로 넘침 없음 확인.

가볍게 즐기는 로컬 게임입니다. 모든 교착 배치를 탐색하는 완전한 dead-position 판정이나 대회용 시계/터치무브는 제공하지 않습니다. 무승부 선언은 이미 충족된 현재 배치 기준이며, 예정 수를 제출하는 사전 선언은 지원하지 않습니다.
