# 마지막 기지 · TANK GUARD

직접 그린 탱크와 벽으로 만든 1인용 기지 방어 HTML5 게임. 외부 라이브러리·폰트·이미지·네트워크 연결 없이 실행합니다.

## 실행
` tank-guard.html `을 내려받아 브라우저로 여세요. GitHub 페이지에서는 파일의 Download raw file 버튼을 사용하세요. index.html은 engine.js/app.js가 같은 폴더에 있어야 합니다.

- 방향키 또는 WASD: 네 방향 이동
- Space: 발사 (누르고 있으면 연사)
- P / Esc: 일시정지·재개. 창을 떠나면 자동 정지
- R: 정지·종료·작전 완료 상태에서 처음으로
- 화면 방향 버튼과 발사 버튼은 터치/포인터 지원

벽돌은 한 발에 부서지고 강철벽은 부서지지 않습니다. 플레이어 목숨은 3개이며 피격 후 2초 동안 보호됩니다. 적탄이 기지에 닿으면 목숨과 관계없이 종료됩니다. 내 탄은 기지를 파괴하지 않습니다. 적은 5/7/9대, 동시에 최대 3대. 세 작전을 마치면 승리합니다. 적은 기지까지의 격자 경로를 찾아 이동하고 벽돌은 사격해 뚫습니다.

## 개발
`python3 build.py`로 단일 HTML을 재생성합니다.
`node --test engine.test.js`로 규칙을 검사합니다(14개).

## 확인 범위 / 한계
데스크톱 브라우저에서 이동, 발사, 벽돌 파괴, 기지 파괴 종료, 재시작, 일시정지와 320px 화면 배치를 확인했습니다. 세 작전 진행은 엔진 테스트로 확인했으며 사람이 세 작전을 모두 클리어한 기록은 없습니다. 실제 휴대폰 멀티터치와 장시간 난이도 균형은 추가 확인이 필요합니다. 소리/저장/온라인 순위/아이템/2인용은 없습니다.

표지(images/cover.webp)는 별도 생성 일러스트이며 실제 게임 그래픽이 아닙니다. 다른 images 이미지는 제작 중 실제 화면 캡처입니다.
