# 박자 사이 · Beat Window

두 줄로 내려오는 노트를 D/K 또는 화면 버튼으로 누르는 짧은 오프라인 HTML5 리듬 게임입니다. 100BPM, 32노트, 약22초이며 외부 음악 파일을 사용하지 않습니다. Web Audio oscillator로 간단한 비트를 합성합니다.

## 실행
`beat-window.html`을 내려받아 최신 브라우저에서 여세요. 시작 버튼을 눌러야 오디오가 활성화됩니다. 인터넷과 설치가 필요 없습니다.

- D: 왼쪽 / K: 오른쪽. 화면 버튼도 지원합니다.
- 정확 ±55ms(100점), 좋아요 ±130ms(60점)
- 일시정지/계속, 처음으로. 창이 비활성화되면 자동 일시정지합니다.
- 입력 보정 -150~150ms: 양수는 늦은 입력에서 보정값을 빼며 다음 판에 적용됩니다. 자동 지연 측정 기능은 아닙니다.
- 노트가 없는 박자의 입력은 점수를 주지 않습니다. 키를 길게 눌러 반복 득점할 수 없습니다.

## 개발
`engine.js`는 판정/콤보/결과, `app.js`는 Canvas/오디오/입력, `index.html`은 UI입니다.
`python3 build.py`로 단일 실행파일을 만들고 `node --test tests/engine.test.js`로13개 검증을 실행합니다.

오디오의 currentTime을 공통 기준으로 쓰고 비트를 짧게 미리 예약합니다. 하드웨어의 출력 지연이나 Bluetooth 지연을 자동으로 측정하지는 않습니다. 실제 장치에서의 청취 비교는 추가로 필요합니다. 390px 화면에서 가로 넘침이 없는지 확인했습니다.

블로그 이미지: 표지는 생성 일러스트, 나머지는 실제 실행 캡처입니다. 실행 확인에서1노트60점과 일시정지/재개/종료를 확인했으며 캡처의 결과는 사람의 플레이 실력을 나타내는 기록이 아닙니다.
