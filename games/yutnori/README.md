# 윷 한 판

오프라인 로컬 2인용 윷놀이. 청팀(teal) vs 홍팀(coral), 각 4개 말.

## 실행

`yutnori.html`을 브라우저에서 바로 열면 됩니다 (의존성/CDN 없음, 오프라인 동작).
개발용으로는 `index.html` + `engine.js` + `app.js`를 함께 열어도 동일하게 동작합니다.

`python3 build.py`를 실행하면 `index.html` + `engine.js` + `app.js`를 하나로 합쳐 `yutnori.html`을 재생성합니다.

## 확률 모델

윷가락 네 개가 각각 독립적으로 50% 확률로 평평한 면 또는 둥근 면이 나온다고 가정한 단순화된 시뮬레이션입니다.
실제 윷가락의 물리적 확률을 측정/반영한 것이 아닙니다. 평평한 면 개수: 1=도(1칸), 2=개(2칸), 3=걸(3칸), 4=윷(4칸), 0=모(5칸).

## 하우스 룰

- 빽도, 낙 없음 (모든 이동은 앞으로만).
- 모서리(o5, o10) 지름길은 그 칸에서 이동을 "시작"할 때만 자동 적용.
- 중앙 칸에서 이동을 시작하면 항상 우하단 경로로 진행.
- 윷/모는 이동 전에 추가로 한 번 더 던짐 (결과는 큐에 쌓여 순서 없이 선택 가능).
- 상대 말을 잡으면 그 칸의 상대 말 전체가 대기 상태로 돌아가고, 사용한 결과가 도/개/걸(1~3)일 때만 추가 던지기 1회 부여 (윷/모는 중복 보너스 없음).
- 같은 팀 말은 같은 칸에서 자동으로 묶여 함께 이동 (분할 불가).
- 출구 칸(o20)을 지나 한 칸 더 가면 완주. 정확히 출구 칸 도착은 아직 보드 위, 초과 이동도 완주 처리.
- 한 팀 말 4개가 모두 완주하면 승리.

## 파일 구성

- `engine.js` - 게임 로직 (CommonJS + `window.YutEngine`, DOM 의존 없음)
- `app.js` - UI 렌더링/이벤트 처리
- `index.html` - 개발용 진입점 (스크립트 분리 로드)
- `build.py` - `index.html` + `engine.js` + `app.js`를 `yutnori.html`로 번들링
- `yutnori.html` - 배포용 단일 파일 (오프라인 실행 가능)

## 조작

1. 윷 던지기를 누릅니다. 윷/모가 나오면 추가 던지기를 먼저 마칩니다.
2. 사용할 결과를 고르고 대기 중인 말 또는 판 위의 내 말을 선택합니다.
3. 도착할 칸을 확인하고 ‘선택한 말 이동’을 누릅니다.
4. ‘한 단계 되돌리기’로 바로 전 던지기 또는 이동을 취소할 수 있습니다.

## 검증

`node --test test-engine.js` — 출발, 업기, 잡기, 추가 던지기, 지름길, 완주, 승리, 되돌리기 등 12개 테스트.
실제 브라우저에서 한 판을 끝까지 진행해 홍팀 4개 말 완주와 승리 후 입력 차단을 확인했습니다. 320px 화면에서 가로 넘침이 없음을 확인했습니다.
